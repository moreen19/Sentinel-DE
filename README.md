# Sentinel-DE
Agentic system grounded in an "Expertise Matrix" to handle system owner identification and business criticality weighting.

**•	The Problem:** Identified a senior-level bottleneck where manual triage of failing data assets cost the team 1.25 hours daily.
**•	The Solution:** Architected an automated agentic system grounded in an "Expertise Matrix" to handle system owner identification and business criticality weighting.
**•	The Results:** Achieved 96% routing accuracy and 100% data integrity in meeting logs; transitioned the team to an exception-based handling model.
